Values are read once at start. Booleans accept `true`, `false`, `1`, `0`, `yes` and `no`. An empty value counts as unset. A bad value stops the process with a list of problems. Guidance is in [Configuration](/self-hosting/configuration/).

<InstanceSettingNote setting="Settings moving to the dashboard">
Variables with the **Instance settings** badge are being moved into the instance admin UI: who can create workspaces, sign-in methods, SMTP, the Slack app and the instance's single sign-on providers. Set them in Instance settings, or by the environment variable as the initial value. See [Instance settings](/self-hosting/instance-settings/).
</InstanceSettingNote>

The Docker Compose file only passes through the variables it lists: see [Docker Compose](/self-hosting/docker-compose/).
