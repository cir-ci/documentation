CirCI stores screenshots, diff images, thumbnails and hosted sites as files. Each file is named by its SHA-256 hash and checked when it's written, so an unchanged screenshot is uploaded and stored once, however many builds contain it. Storage grows with *changes*, not builds.

## Choose a driver

<Tabs>
<TabItem label="Local disk">

The default and the cheapest. Uploads go through the API, which writes each file to a temporary location while hashing it and moves it into place only if the hash matches. Back up the volume together with the database: [Backups](/self-hosting/backups/).

<SettingCard name="STORAGE_DRIVER" defaultValue="fs">
`fs` for local disk.
</SettingCard>

<SettingCard name="STORAGE_PATH" defaultValue="/var/lib/circi/files" type="path">
The directory. In the compose file it's the `files` Docker volume.
</SettingCard>

</TabItem>
<TabItem label="S3 and compatible">

AWS S3, Cloudflare R2, Backblaze B2, MinIO or LocalStack.

<SettingCard name="STORAGE_DRIVER" defaultValue="fs">
`s3` for any S3-compatible service.
</SettingCard>

<SettingCard name="S3_BUCKET" required type="string">
The bucket. Required with the `s3` driver.
</SettingCard>

<SettingCard name="S3_REGION" defaultValue="us-east-1">
The bucket's region.
</SettingCard>

<SettingCard name="S3_ENDPOINT" type="URL">
A custom endpoint for R2, B2, MinIO or LocalStack, such as `https://<account>.r2.cloudflarestorage.com`. Leave it empty for AWS.
</SettingCard>

<SettingCard name="S3_FORCE_PATH_STYLE" defaultValue="true when S3_ENDPOINT is set" type="boolean">
Path-style addressing, which MinIO and LocalStack need.
</SettingCard>

<SettingCard name="S3_ACCESS_KEY_ID, S3_SECRET_ACCESS_KEY">
Set both, or neither to use the AWS credential chain (an IAM role is best on AWS).
</SettingCard>

<SettingCard name="S3_CONNECT_TIMEOUT_SECONDS, S3_REQUEST_TIMEOUT_SECONDS" defaultValue="10 and 60">
Seconds. The first is how long to wait for a connection before giving up. The second is how long a request may sit idle with no data moving, not how long it may take in total, so large files keep flowing.
</SettingCard>

</TabItem>
</Tabs>

The storage driver is read-only in Instance settings: it names `STORAGE_DRIVER` and is changed there, with a restart.

With S3 the CLI uploads **directly to the bucket** through presigned URLs bound to the file's SHA-256 checksum (the `x-amz-checksum-sha256` header, supported by AWS S3, R2 and MinIO), so storage rejects bytes that don't match, and finalize then confirms each object. The bucket must be reachable from where CI runs.

<Aside type="tip" title="Keeping the bill down">
Egress and storage are the main costs. Object storage with free egress (Cloudflare R2, Backblaze B2 behind Cloudflare, or MinIO on the same disk) cuts the most. Shorter [retention](/self-hosting/retention-and-gc/) for projects that don't need history helps next.
</Aside>

## SeaweedFS and LocalStack for development

`docker-compose.s3.yml` adds a local SeaweedFS (S3 API on host port 9000, `S3_PORT` to change it) with a `circi` bucket, created by an `aws-cli` init container, and points the app at it. Any S3-compatible service works instead, MinIO included. The end-to-end suite uses LocalStack for S3. Neither is meant for production.

## Moving between storages

```sh
# local disk to S3
circi admin storage migrate --to s3 --bucket circi --region eu-west-1
# S3 (or anything) to a directory
circi admin storage migrate --to fs --path /mnt/files
```

It copies every stored file to the new storage under the same keys and reports the `Copied`, `already there`, `missing at the source` and `failed` counts. It exits 1 if any copy failed. When it succeeds it tells you to set `STORAGE_DRIVER` (and its settings) and restart. Other options: `--endpoint`, `--force-path-style`. The target bucket's keys come from `S3_ACCESS_KEY_ID` and `S3_SECRET_ACCESS_KEY` (or their `_FILE` forms) when both are set, otherwise from the AWS credential chain.

## What is using space

Files and bytes by kind, and what is waiting to be deleted:

```sh
circi admin storage usage
```

## Check that storage works

`circi admin doctor` checks that the storage is usable and, for local disk, the free space. **Instance** › **Health** shows the same, and `GET /readyz` includes storage.
