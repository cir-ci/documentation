## What the page lists

Each entry names the environment variable behind it.

| Section | Setting | Environment variable |
|---|---|---|
| Dashboard address | The address, and old addresses that redirect to it | `PUBLIC_URL`, `PREVIOUS_PUBLIC_URLS` |
| Sign-in methods | Which methods the instance accepts: password, email code, single sign-on | `AUTH_PASSWORD_ENABLED`, `AUTH_EMAIL_ENABLED`, `AUTH_SSO_ENABLED` |
| Who can create workspaces | Instance admins only, or everyone | `WORKSPACE_CREATION` |
| Storage and limits | The storage driver, the grace period before unused files are deleted, the upload timeout, whether webhooks may call private addresses | `STORAGE_DRIVER`, `GC_GRACE_HOURS`, `UPLOAD_TIMEOUT_MINUTES`, `WEBHOOK_ALLOW_PRIVATE_ADDRESSES` |
| Hosted sites | The sites domain, or "Not set up" | `STATIC_SITES_HOST` |
| Mail | The SMTP server and sender, and a button that sends a test mail to your own address | `SMTP_*` |

<Aside type="caution">
Where an entry isn't editable yet, change the environment variable and restart. The page also shows the default retention of new Projects (30 days) beside a `DEFAULT_PROJECT_RETENTION_DAYS` label, but the server doesn't read that variable: the default is built in, and each Project sets its own in its settings.
</Aside>

## The other Instance pages

| Page | What it does |
|---|---|
| **Accounts** | Every account. Change an email, ban or unban. |
| **Workspaces** | Every Workspace on the instance, deleted ones too, and creating one. Instance admins manage accounts and Workspaces but see the Projects only of the Workspaces they belong to. |
| **Health** | The same checks as `circi admin doctor`, the services including queue depth, the domains and cookies check, and the **Setup code**. |
| **GitHub App** | Create the GitHub App with the manifest flow, or see the one configured. See [GitHub](/integrations/github/). |

## Settings that stay environment variables

Deployment-level values stay environment variables: `DATABASE_URL`, `BETTER_AUTH_SECRET`, `PUBLIC_URL`, `HOST`, `PORT`, the storage settings, `TRUSTED_PROXIES` and `CIRCI_DIFF_ENGINE`. The [environment variable reference](/reference/environment-variables/) marks the ones that are moving.
