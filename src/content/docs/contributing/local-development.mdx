## Set up

You need Node 26 (`nvm install && nvm use` reads `.nvmrc`), pnpm 12 and, for `pnpm dev`, Docker.

<Steps>

1. Install the dependencies.

   <CopyCommand client:visible command="pnpm install" />

2. Install Chromium once. Component tests run in headless Chromium.

   <CopyCommand client:visible command="pnpm exec playwright install chromium" />

3. Start the QA environment.

   <CopyCommand client:visible command="pnpm dev" />

</Steps>

## `pnpm dev`

`pnpm dev` is the local QA environment, and the dashboard on **http://localhost:5173** is what you open. It starts:

| Part | What runs | Where |
| --- | --- | --- |
| Postgres and Mailpit | Docker containers (Compose project `circi-dev`) | Mailpit catches every email the server sends |
| The server and worker | `circi all` from source under `node --watch`, so a change restarts it | Port 3000 |
| The dashboard | Vite with hot reload. It proxies every server path to the server | Port 5173 (`PUBLIC_URL`) |

On the first run it seeds `owner@example.com` and `member@example.com` (password `circi-dev-password`), the workspace `acme`, the project `web-app` and builds in different review states, so every screen has something to show.

```sh
pnpm dev          # Ctrl+C stops it and keeps the data
pnpm dev:reset    # delete the dev database and files; the next pnpm dev seeds again
```

To run the server from source against your own Postgres:

```sh
DATABASE_URL=postgres://… BETTER_AUTH_SECRET=$(openssl rand -base64 32) STORAGE_PATH=./data pnpm circi all
```

## Before committing: `pnpm gate`

Run the formatter, then the gate.

```sh
pnpm format       # oxfmt
pnpm gate         # Turborepo: format check, lint, typecheck, tests and build
```

`pnpm gate` runs these in parallel where they're independent, each cached by its inputs, so a second run on an unchanged tree is instant:

| Task | What it checks |
| --- | --- |
| Format check | oxfmt |
| Lint | oxlint, type-aware, plus the layer rules from [Repo layout](/contributing/repo-layout/) |
| Typecheck | `tsc` with `noEmit` |
| Tests | The Node, UI and web browser projects (see [Tests](/contributing/tests/)) |
| Build | tsdown for `@circi/ui`, `@circi/cli`, `@circi/vitest` and the server bundle, then Vite for the dashboard |

`pnpm gate:full` adds the two end-to-end groups, which need Docker and Chromium. The older chain `pnpm lint && pnpm typecheck && pnpm test && pnpm build` still works.

`tsc` only type-checks. Packages other than the four above have no build: their `exports` point at `src/*.ts`, which Node, Vitest, Vite, tsc and tsdown all read directly.

## Database changes

Edit the table files in `packages/db/src/schema/`, then run `pnpm db:generate`, which writes a SQL migration to `packages/db/migrations/`. Commit both. After changing better-auth's plugins run `pnpm db:auth-schema`, then `pnpm db:generate`.

## Performance suite

`pnpm perf` runs the k6 suite against a fresh stack. `pnpm perf:down` tears it down and `pnpm perf:bench` runs the diff microbenchmark. Results are in `docs/perf`.

## Commits

Commit messages end with the project's `Co-Authored-By` line (see `CLAUDE.md`).

<Aside type="tip">
`pnpm test:visual` screenshots every `@circi/ui` component in light and dark with `@circi/vitest`, and uploads to a CirCI when `CIRCI_API_URL` and `CIRCI_TOKEN` are set. CirCI tests its own design system with itself.
</Aside>
