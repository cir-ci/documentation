<section class="l-section" aria-labelledby="paths">

  <div class="l-paths">
    <div class="l-path">
      <h3><a href="/getting-started/run-it-locally/">Run it locally</a></h3>
      <p>Start the app and Postgres with Docker Compose, create a Project and upload a first build.</p>
      <code>docker compose up -d --build</code>
    </div>
    <div class="l-path">
      <h3><a href="/self-hosting/requirements/">Self-host</a></h3>
      <p>Requirements, TLS, storage, upgrades, backups and every environment variable.</p>
      <span class="hint">One image: server, worker and dashboard.</span>
    </div>
    <div class="l-path">
      <h3><a href="/ci/cli/">Set up CI</a></h3>
      <p>Upload from any CI with the <code>circi</code> CLI or the Vitest plugin. Shallow checkouts work.</p>
      <code>npx circi upload ./screenshots --wait</code>
    </div>
    <div class="l-path">
      <h3><a href="/using/reviewing-a-build/">Review builds</a></h3>
      <p>Approve or reject each screenshot, comment on a region, and ask for reviews.</p>
      <span class="hint">In a build, <Kbd keys="Shift+A" /> approves everything.</span>
    </div>
  </div>
</section>
