CirCI implements the upload API of the Argos SDKs under `/v2`, so that a project that uploads with `@argos-ci/playwright`, `@argos-ci/cypress`, `@argos-ci/storybook` or `@argos-ci/cli` could switch by changing two values. **It doesn't work with the real SDK yet** (see the status below):

```sh
ARGOS_API_BASE_URL=https://ci.acme.io/v2
ARGOS_TOKEN=circi_…          # the project's CI token
```

`circi argos-env` prints exactly these two lines from `CIRCI_API_URL` and `CIRCI_TOKEN`. To use Playwright without the Argos SDK, write its screenshots to a folder for the CLI: see [Playwright](/ci/playwright/).

<Aside type="caution" title="Status: tried with the real SDK, and it fails">
Built from the source of `@argos-ci/core` `upload()`, and then tried with the real `@argos-ci/cypress` 7.6.0 (`@argos-ci/core` 6.9.1) and Cypress 16.3.0 against a local CirCI. The SDK refuses the setup before it uploads anything: its token check accepts only 40 characters (or an `argos_oat_` prefix) and a CirCI token has 49, and it refuses `localhost` as an address. After removing the token check in a scratch copy of the SDK, it crashed on the shape of CirCI's baseline reply (`baseline.head.sha` is missing); with that read changed too, a build was created, processed and showed the screenshot. The details are on the [Cypress page](/ci/cypress/#the-argos-sdk-for-cypress-doesnt-work-with-circi-yet). The SDKs share `@argos-ci/core`, so the same checks apply to the others, which weren't run. Use `circi upload`, the [Vitest plugin](/ci/vitest/) or the [Cypress plugin](/ci/cypress/) until it's fixed.
</Aside>

## What works

- Project lookup, baseline lookup from the commit history the SDK collected, build creation, the file upload target, updates in chunks, parallel builds (`parallel`, `parallelNonce`, `parallelIndex`, `parallelTotal`) and build names.
- The history the SDK collected finds the baseline. The build's **Details** tab shows it as "where this branch started".
- Pull request number, branch, and reference branch and commit.

## What doesn't

- **PNG only.** An SDK sending JPEG is refused.
- Traces, per-screenshot thresholds, `parentName` and `baseName`, and merge queue fields are accepted and ignored.
- Manually finalized parallel builds (`parallelTotal: -1`) are refused: pass the real total.
- No Argos GitHub bot behavior comes with the SDK: link the repository to CirCI's own GitHub App instead ([GitHub](/integrations/github/)).

## Moving the history

Existing Argos builds aren't imported. The first build on your default branch after switching becomes the baseline once someone approves it (a first build is never approved automatically). After that, auto-approve on the default branch (on by default) keeps the baseline moving without review.

## Endpoints

Under `/v2`, with `Authorization: Bearer circi_…`: `GET /project`, `POST /baseline`, `POST /builds`, `PUT /builds/:id`. The upload target `POST /uploads/:buildId/:sha256` (multipart) takes no token: it accepts a file only under its own SHA-256 hash. See the [HTTP API overview](/reference/http-api/).
